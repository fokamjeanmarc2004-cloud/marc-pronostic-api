01 Code promo Melbet RDC (Congo-Kinshasa) : ce que tu obtiens

Si tu paries en RDC, le code FFN est le code partenaire à utiliser sur Melbet. Il ne coûte rien : il sert uniquement à activer le bonus de bienvenue maximum au moment de l'inscription.

Pour un compte ouvert en RDC avec la devise franc congolais (CDF), le bonus est de 300% jusqu'à 300 000 FCFA sur ton premier dépôt.

⚠️ Le code se saisit pendant la création du compte. Une fois le compte créé sans code, il n'est plus possible de l'ajouter.

02 Inscription Melbet en RDC : les étapes

  1. Ouvre Melbet avec le bouton ci-dessus ou télécharge l'application.
  2. Choisis « RDC (Congo-Kinshasa) » comme pays et CDF comme devise.
  3. Renseigne ton numéro de téléphone congolais (celui lié à ton compte Mobile Money).
  4. Colle le code FFN dans le champ « Code promo ».

05 Questions fréquentes — Melbet RDC (Congo-Kinshasa)

Le code promo Melbet FFN est-il gratuit en RDC ?

Oui, 100% gratuit. Il ne fait qu'activer le bonus de bienvenue maximum pour un compte congolais.

Quel est le montant du bonus en RDC ?

Le bonus correspond à 300% jusqu'à 300 000 FCFA sur ton premier dépôt. Montant indicatif, il peut évoluer selon les promotions en cours.

Puis-je déposer avec M-Pesa (Vodacom) ?

Oui. M-Pesa (Vodacom) est l'un des moyens de dépôt les plus utilisés en RDC sur Melbet. Le compte est crédité en quelques minutes.

Faut-il vérifier son compte pour retirer ?

Oui. Une pièce d'identité est demandée avant le premier retrait important. Utilise tes vraies informations à l'inscription : un nom qui ne correspond pas à ta pièce bloque le retrait.

Je suis congolais mais je vis à l'étranger, que choisir ?

Choisis le pays où tu résides réellement et où se trouve ton moyen de paiement. Le code FFN reste valable dans tous les cas.
